## Общий принцип

Одна «клетка» — два пробела (`CELL = '  '`). Символ терминала примерно вдвое выше своей ширины, поэтому клетка получается почти квадратной. Цвет задаётся escape-последовательностью фона, после клеток идёт сброс:

| Константа | Escape-последовательность | Цвет |
| --------- | ------------------------- | ---- |
| `RED`     | `\u001b[41m` | красный |
| `GREEN`   | `\u001b[42m` | зелёный |
| `BLUE`    | `\u001b[44m` | синий |
| `WHITE`   | `\u001b[47m` | белый |
| `END`     | `\u001b[0m`  | сброс форматирования |

## 1. Флаг Швейцарии — `draw_flag()`

Флаг — сетка 25×15 клеток, красный фон и белый крест по центру. Толщина перекладин 3 клетки. Отступы креста от краёв считаются от размеров:

- `MARGIN_V = HEIGHT * 0.2` — отступ сверху и снизу (3 клетки);
- `MARGIN_H = (WIDTH - HEIGHT) // 2 + MARGIN_V` — отступ слева и справа (8 клеток). Так горизонтальное плечо получается той же длины, что и вертикальное: крест 9×9 клеток и не доходит до краёв.

Клетка белая, если она лежит в вертикальной или в горизонтальной перекладине, иначе красная:

```python
vertical = abs(col - WIDTH // 2) <= 1 and MARGIN_V <= row < HEIGHT - MARGIN_V
horizontal = abs(row - HEIGHT // 2) <= 1 and MARGIN_H <= col < WIDTH - MARGIN_H
color = WHITE if vertical or horizontal else RED
```

## 2. Узор `j` — `draw_pattern()`

Узор `j` — два кольца рядом. Кольцо задано битовой картой 7×7 (`RING`, `#` — закрашенная клетка), а функция повторяет её: 2 пары (4 кольца) по горизонтали и 3 ряда по вертикали.

```python
RING = [
    '  ###  ',
    ' #   # ',
    '#     #',
    '#     #',
    '#     #',
    ' #   # ',
    '  ###  ',
]

def draw_pattern(across=2, down=3):
    for _ in range(down):
        for row in RING:
            print(''.join(f'{BLUE}{CELL}{END}' if c == '#' else CELL for c in row * 2 * across))
```

## 3. График `y = x / 3` — `draw_function()`

График первой четверти, 9 строк в высоту (`y` от 0 до 8). По горизонтали `x` идёт от 0 до 24: ширина `3 * (9 - 1) + 1 = 25` подобрана так, чтобы верхняя точка `y = 8` пришлась на `x = 24`. Клетка `(x, y)` закрашивается зелёным, если `round(x / 3) == y`. Получается ступенчатая линия с наклоном 1/3 (по 3 клетки на ступень). Слева подписаны значения `y`, под осью `x` — каждое третье значение.

```python
for y in range(height - 1, -1, -1):
    cells = ''.join(f'{GREEN}{CELL}{END}' if round(x / 3) == y else CELL for x in range(width))
    print(f'{y:2d} |{cells}')
```

## 4. Диаграмма по `sequence.txt` — `draw_sequence_diagram()`

Числа читаются из файла в список `float`. Числа делятся на две группы: попавшие в отрезок `[-3; 3]` (границы включены) и все остальные. Количество берётся через `len` от списка:

```python
inside = len([n for n in numbers if -3 <= n <= 3])
outside = total - inside
```

Диаграмма — одна полоса шириной 35 клеток, зелёная часть пропорциональна доле чисел из `[-3; 3]`, красная — остальным. Под полосой легенда с процентами.

Результат: всего 250 чисел, из них 76 в отрезке `[-3; 3]` (30.4%), остальных 174 (69.6%). Зелёных клеток `round(76 / 250 * 35) = 11`, красных 24.

## 5. Допзадание: анимация — `animate()`

Анимация из 5 кадров: полоса из 10 клеток постепенно заливается белым слева направо (0, 3, 5, 7 и 10 белых клеток из 10). Между кадрами консоль очищается через `os.system('clear')`, пауза 0.5 с (`sleep`). Так как `clear` стирает весь экран, перед анимацией программа ждёт нажатия Enter, чтобы можно было рассмотреть остальной вывод.
